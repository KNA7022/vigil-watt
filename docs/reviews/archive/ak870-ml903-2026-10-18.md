# 黑爵 / 雷神适配与任务栏位置审查

## 1. 基线与边界

基线 46efacb（1.2.2），贡献者 KNA7022。范围为两个品牌插件、协议解析与测试、任务栏偏移设置和拖动计时器。2026-10-18 在适配版上查询实机并确认读数；2026-10-19 合入当前基线后进行了构建与回归测试，未重复实机验证。

## 2. 发现

原迈从候选规则与 ML903 的 64/64 接口冲突；当前基线已使用 MchoseInterfaceClassifier 的 VID 白名单，本改动增加黑爵和雷神接口不能被迈从认领的回归测试。TaskbarPillWindow.ReleaseWindow 在销毁前结束拖动，避免重建窗口后计时器仍访问旧窗口。

## 3. 复核

R1/R2：两个插件默认关闭、继承 BatteryPluginBase，查询有明确来源，使用 WritesEnabled / CanWrite。R3/R4：IO 复用基类锁与句柄释放；拖动计时器在 UI 线程运行，松开、销毁和 Dispose 都停止计时器。R5：沿用 HID 层异常日志，异常帧不写入读数。R6/R7/R8：协议文档保留来源，解析纯函数可独立测试。品牌中英文展示符合 AGENTS.md §9，配置键和具体设备名称保持兼容。

验证：sln Debug 构建零警告零错误；相关 107 项测试通过，包含实机帧解析、接口隔离、任务栏布局及上游相关回归用例。

## 4. 未证实

充电状态缺少充分证据，保持 Unknown。其他固件、有线及蓝牙模式、鼠标断电后的响应行为未验证。任务栏真实拖动手感、竖向、多屏和自动隐藏仍需人工验证，不将静态修复与布局单测等同于实机结论。

## 5. 结论去向

无新增未修代码缺陷。原有 CR-41、CR-48 继续保留于 BACKLOG；协议与硬件边界见 `docs/hardware/ak870-ml903.md`。不修改原项目发布版本或打包产物。
