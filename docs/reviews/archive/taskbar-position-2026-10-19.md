# 任务栏位置调整审查

## 1. 基线与边界
基于 46efacb，贡献者 KNA7022。仅含任务栏偏移设置、拖动计时器及 Win32 按键状态读取，不包含设备插件。

## 2. 发现
非前台任务栏子窗口可能漏掉跨窗口鼠标消息，增加拖动期间光标轮询。窗口销毁前结束拖动，防止计时器访问旧窗口。设置页未编辑偏移时保留新拖动位置。

## 3. 复核
计时器只在 UI 线程运行，松开、销毁、Dispose 均停止。偏移复用已有 DPI 换算与持久化字段，输入限定范围并排除非有限值。独立分支构建零警告零错误，18 项 TaskbarLayoutTests 通过。

## 4. 未证实
真实拖动手感、竖向、多屏、自动隐藏仍需人工验证；布局单测不等同于实机拖动验证。

## 5. 结论去向
无新增未修代码缺陷，原有 CR-41、CR-48 保留于 BACKLOG。设置 → 任务栏 → 位置偏移，负数左移、正数右移、0 复位，竖向任务栏对应上下；保存后生效。
